# Gouvernance du projet

## Rôles
- Maintainers: pilotent la vision, releases, revues critiques
- Triage: classent issues/PR, labels
- Contributors: proposent des changements via PR

## Prise de décision
- Changements majeurs via RFC (`docs/RFCS`)
- Consensus approché entre maintainers
- Conflits: vote des maintainers

## Release
- SemVer: MAJOR.MINOR.PATCH
- Cadence: mineures toutes les 6-8 semaines, patchs au fil de l’eau
- Changelog: `CHANGELOG.md`

## Code de conduite
Tous les participants doivent respecter `CODE_OF_CONDUCT.md`.
